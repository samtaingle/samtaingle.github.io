## Run Locally

Clone the repository:

```bash
git clone https://github.com/samtaingle/samtaingle.github.io.git
```

Navigate to the project directory:

```bash
cd samtaingle.github.io
```

Run a local server:

```bash
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```
